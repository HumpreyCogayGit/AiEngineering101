AI Engineering: Building with LLMs

A practical, hands-on journey through modern AI engineering. Start with LLM APIs and progressively build working systems using RAG, tool calling, agents, MCP, memory, guardrails, and evaluation.

The focus is on understanding how these components work, how they fit together, and how to implement them in real applications. Each lecture includes a runnable exercise to put the concepts into practice.

How this course works

Every lecture pairs with an exercise folder of the same number: lec005.html ↔ EXER005/. Each lecture explains the concept, describes the project, lists the goal and success criteria, and discusses the trade-offs and pitfalls. It ends with a short Check Yourself quiz: two minutes, for you and not a grade. Your score appears next to the lecture in the list below.

All the exercise folders, with starter code and reference solutions, come in one repository that you download once: git clone https://github.com/HumpreyCogayGit/AiEngineering101.git, or use Code → Download ZIP on GitHub. The setup guide walks through it.

EXER005/
├── README.md     the brief: tasks, how to run, success criteria
├── starter/      YOUR code — complete the TODOs here
├── solution/     a reference solution (try first, peek later)
├── stretch/      reference code for the two optional stretch goals
└── check.py      automated checks for the success criteria
# always run from the repository root
uv run python EXER005/starter/chatbot.py      # run your code
uv run python EXER005/check.py                # check your code
uv run python EXER005/check.py --solution     # check the reference solution
Two principles

Raw first, framework second. You call the API with plain HTTP before using the SDK, and write a tool loop by hand before LangChain does it for you. You'll know what the framework hides.

Measure, don't guess. Checks marked [live API] call your real model; others run offline with fake models. From Module 4 on you build your own evaluations.

Before you start

You need a computer with macOS, Linux or Windows, basic comfort with a terminal, and an inference provider: an Azure subscription, or Ollama installed locally. Little Python experience is fine: Lecture 002 covers what you need. Follow the setup guide first.
