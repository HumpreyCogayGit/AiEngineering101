How this course works

Every lecture pairs with an exercise folder of the same number: lec005.html ↔ EXER005/. Each lecture explains the concept, describes the project, lists the goal and success criteria, and discusses the trade-offs and pitfalls.

EXER005/
├── README.md     the brief: tasks, how to run, success criteria
├── starter/      YOUR code — complete the TODOs here
├── solution/     a reference solution (try first, peek later)
└── check.py      automated checks for the success criteria
# always run from the repository root
uv run python EXER005/starter/chatbot.py      # run your code
uv run python EXER005/check.py                # check your code
uv run python EXER005/check.py --solution     # check the reference solution
Two principles

Raw first, framework second. You call the API with plain HTTP before using the SDK, and write a tool loop by hand before LangChain does it for you. You'll know what the framework hides.

Measure, don't guess. Checks marked [live API] call your real Azure deployment; others run offline with fake models. From Module 4 on you build your own evaluations.
